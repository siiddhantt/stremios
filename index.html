StremIOS

A free, open-source public beta of a native Stremio-compatible iPad client.

Rootful jailbreak · arm64 iPad · iOS 12.x
Tested on iPad mini 2 with iOS 12.5.8. The jailbreak must be active.

Already installed using an IPA?

Keep that installation and update it with the IPA. This package refuses an automatic migration from an IPA. It never uninstalls an IPA or deletes its saved data. Package removal removes the app, not its saved data.

Before installing

No content, accounts or paid provider access is included. Configure your own supported add-ons. Other devices, rootless jailbreaks and modern iOS are not validated. Prefer 720p on this hardware. This beta does not promise universal source compatibility or battery performance.

Version 0.8.3~beta1. Independent project; not affiliated with Stremio.
